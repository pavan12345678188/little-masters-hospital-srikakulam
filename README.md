# Little Masters Children’s Hospital — Advanced Marketing Website

Premium React + Vite website for Little Masters Children’s Hospital & Diagnostic Centre, Srikakulam.

## Features
- Modern, animated UI with Framer Motion
- Responsive design optimized for all devices
- Hero section with floating orbs and smooth animations
- Services, Doctors, Facilities, FAQ, and Contact sections
- WhatsApp floating button + call-to-action
- Logo integration
- Google rating showcase
- Smooth scroll and sticky header

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```
Output in `dist/`.

**Note:** This is a demo/marketing concept. Confirm all doctor details, contact numbers, and services before going live. The enquiry form is visual only.
